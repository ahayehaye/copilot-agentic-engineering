# research/ — the research library

A living library of technical research. One page per topic.

## Content contract

- **Cited, sourced, dated.** Every non-obvious claim carries a source URL.
- **Written to be re-read in six months** and still make sense — no
  "as discussed above" without the above.
- **Living, not a backlog.** Revisiting a topic updates the file in place and
  bumps the `last-verified` line. It does not close, and it does not spawn a
  new file.
- **Status is honest.** `draft` = actively being worked; `evergreen` =
  settled, re-verify only when the upstream changes; `stale` = known to have
  drifted, needs a pass.

## Index

`index.md` is read first, topic files second (progressive disclosure).

## Distinction

This library is distinct from the `tickets/research/` namespace: the
namespace holds ticket-driven investigations (the work); this library holds
the cited, dated, living entries (the evidence).
