# copilot-agentic-engineering

A collection of reusable **agent skills**, **MCP servers**, and **Copilot agents**, developed in-repo and deployed locally from source through a shared manager library. This repository is a navigation hub: all procedural content — how to add skills, manage servers, and use the manager library — lives on the topic pages below.
